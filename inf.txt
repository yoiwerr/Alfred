<details>
<summary>📋 提示词：生成 Spring Boot 后端项目（点击展开）</summary>

请帮我创建一个 Spring Boot 3.x 后端项目，用于本地匿名论坛。
技术栈

- Spring Boot 3.x + Spring Web + Spring Data JPA
- MySQL 驱动
- Maven 管理依赖
- Java 17+
数据库

- 数据库名 forum，已有 posts 表和 comments 表（建表 SQL 见下方）
- 请使用 application.properties 配置数据源
建表 SQL（已执行）

sql
CREATE DATABASE IF NOT EXISTS forum CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE forum;
CREATE TABLE posts (
id BIGINT AUTO_INCREMENT PRIMARY KEY,
title VARCHAR(255) NOT NULL,
content TEXT NOT NULL,
created_at DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;

CREATE TABLE comments (
id BIGINT AUTO_INCREMENT PRIMARY KEY,
post_id BIGINT NOT NULL,
content TEXT NOT NULL,
created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
FOREIGN KEY (post_id) REFERENCES posts(id)
) ENGINE=InnoDB;


需求

实体类

- Post 实体：id, title, content, createdAt
- Comment 实体：id, postId, content, createdAt
- 不需要用户实体
JPA Repository

- PostRepository：继承 JpaRepository，额外提供按 createdAt 降序查询
- CommentRepository：继承 JpaRepository，按 postId 查询并按 createdAt 升序
REST Controller（所有接口前缀 /api）

1. GET /api/posts — 返回帖子列表（按时间倒序），每条含评论数
2. GET /api/posts/{id} — 返回帖子详情 + 该帖所有评论
3. POST /api/posts — 创建帖子，请求体 {title, content}
4. POST /api/posts/{id}/comments — 添加评论，请求体 {content}
跨域配置

- 添加 CORS 配置，允许 localhost 所有端口的请求
其他

- application.properties 中 MySQL 连接信息用占位符（用户名/密码），我会自行填写
- 端口默认 8080
- 不需要任何认证/鉴权逻辑
- 不需要单元测试
请生成完整的项目结构，包括 pom.xml、所有 Java 源文件、application.properties。
